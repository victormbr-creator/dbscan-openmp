# Uso responsable de IA

Se utilizó Codex de OpenAI para inspeccionar archivos, diagnosticar rutas, asistir en el generador Python, implementar C++/OpenMP, diseñar validaciones y automatización, ejecutar comandos y redactar documentación. El código nuevo y estos documentos fueron asistidos por IA. El notebook del profesor se mantuvo intacto.

La verificación incluyó ejecución real, compilación, comparación punto por punto con sklearn y pruebas de casos límite. Los tiempos publicados provienen de los CSV medidos. La IA detectó y documentó diferencias de precisión entre backends de referencia; no ajustó resultados para alcanzar una aceleración objetivo.
