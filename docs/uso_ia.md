# Uso responsable de IA

Utilicé Codex de OpenAI como apoyo para inspeccionar archivos, preparar el generador Python, desarrollar las implementaciones C++/OpenMP, diseñar pruebas, automatizar experimentos y redactar documentación. El código y los documentos de este proyecto fueron asistidos por IA; no los presento como trabajo realizado sin esa ayuda. Mantuve intacto el notebook del profesor.

La asistencia incluyó la ejecución de compilaciones, pruebas y mediciones. Para verificar el proyecto utilicé comparaciones punto por punto con scikit-learn, casos límite y auditorías entre P0, P1 y P2. Los tiempos que reporto provienen de los CSV experimentales y no de estimaciones inventadas.
