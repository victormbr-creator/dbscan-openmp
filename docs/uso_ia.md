# Uso responsable de IA

Utilicé Codex de OpenAI como apoyo para inspeccionar archivos, preparar el generador Python, desarrollar las implementaciones C++/OpenMP, diseñar pruebas, automatizar experimentos y redactar documentación. El código y los documentos de este proyecto fueron asistidos por IA; no los presento como trabajo realizado sin esa ayuda. Mantuve intacto el notebook del profesor.

La asistencia incluyó la ejecución de compilaciones, pruebas y mediciones. Para verificar el proyecto utilicé comparaciones punto por punto con scikit-learn, casos límite y auditorías entre P0, P1 y P2. Los tiempos que reporto provienen de los CSV experimentales y no de estimaciones inventadas. Documenté las discrepancias observadas entre backends de referencia, sin alterar resultados para alcanzar una aceleración objetivo.

Realizo el proyecto de manera individual. Soy responsable de revisar las decisiones técnicas y comprender el código para mi defensa. La validación automatizada aporta evidencia de funcionamiento, pero no sustituye mi comprensión del conteo del propio punto, las dos fases, las barreras, la propiedad exclusiva de cada índice, las consultas globales de P2 y el cálculo del rendimiento.
